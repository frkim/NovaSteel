## The one-line answer

> NovaSteel should fund a **time-boxed, single-line pilot** of an Azure
> **Microsoft Fabric + Microsoft Foundry** optimisation platform that delivers a
> **21-day furnace-failure warning**, **−14% energy/ton**, **−22% CO₂** and
> **+8% high-grade yield** — a business case dominated by avoided **€8M** furnace
> failures and a large energy cost base, with **sub-12-month payback** and a
> de-risked, gated path to four-country scale.
