# Key Takeaways

The essentials of iron, steel, and metal production — summarized.

- **Iron** is a pure element, while **steel** is an alloy made mainly of iron
  and carbon.
- **Cast iron** contains more carbon than steel, making it hard but more brittle.
- **Stainless steel** resists corrosion because it contains chromium.
- The two main modern steelmaking routes are the **blast furnace / basic oxygen
  furnace route** and the **electric arc furnace route**.
- After production, metals are shaped through **casting, rolling, forging,
  extrusion, drawing, and machining**.
