This folder contains an application that simulates a steel production and processing
especially blast furnaces and rolling mills

This application is a composed by:
 - one core backend that run multiple sensors
 - one web application to :
    - global start / Stop
    - have overview on sensors
    - simulator incident (abnormal metric, failures, etc)

Stack:
C#, razor, Azure Container Apps

The main activity of NovaSteel is steel production and processing.

More specifically, the company is focused on:
- Producing raw steel from iron ore and scrap (steelmaking)
 - Manufacturing semi-finished and finished steel products, such as:
    - Flat steel (used in cars, appliances, construction)
    - Long steel (used in beams, rails, infrastructure)

Supplying steel to major industries like automotive, construction, energy, and engineering
