# 11 — Glossary

Definitions of the main terms used throughout the NovaSteel Project Ignition workspace.

| Term | Meaning |
| --- | --- |
| **AI Act** | The EU Artificial Intelligence Act, which sets risk-based rules for AI systems, documentation, oversight, and governance. |
| **Audit trail** | A record of who did what, when, and why, used to support traceability, compliance, and investigations. |
| **Blast furnace** | A high-temperature furnace used to produce molten iron from iron ore, coke, and limestone. |
| **Carbon intensity** | The amount of CO₂ emitted per unit of output or energy consumed. |
| **Cp / Cpk** | Statistical process capability measures used to assess whether a process stays within quality limits. |
| **DPIA** | Data Protection Impact Assessment; a GDPR process for evaluating privacy risks before processing personal data. |
| **Edge compute** | Computing performed near the equipment or plant floor to reduce latency and improve resilience. |
| **EU ETS** | The European Union Emissions Trading System, which prices carbon emissions for covered industries. |
| **Historian** | An industrial time-series system that stores operational telemetry from plant equipment and control systems. |
| **Human-in-the-loop** | A control pattern where people review, approve, or override AI recommendations before action is taken. |
| **Knowledge capture** | The process of collecting operator expertise and converting it into reusable, searchable guidance. |
| **MLOps** | Practices and tooling for deploying, monitoring, and governing machine learning systems in production. |
| **OT** | Operational Technology; systems such as PLCs, SCADA, sensors, and plant automation equipment. |
| **PLC** | Programmable Logic Controller; an industrial controller used to automate equipment and processes. |
| **Predictive maintenance** | Maintenance driven by sensor data and models that forecast equipment degradation before failure. |
| **SCADA** | Supervisory Control and Data Acquisition; systems used to monitor and control industrial processes. |
| **Sensor telemetry** | Time-series data collected from machines, furnaces, and production systems. |
| **SPC** | Statistical Process Control; methods for monitoring process stability and variation over time. |
| **Traceability** | The ability to track materials, decisions, and model outputs back to their source data and process history. |
| **Yield** | The proportion of output that meets the desired quality standard and can be sold as premium product. |

## Project-specific references

| Term | Meaning |
| --- | --- |
| **Project Ignition** | NovaSteel’s AI-powered steel production optimization platform. |
| **Time-boxed pilot** | A limited first deployment used to validate value, risk, and feasibility before scaling. |
| **Operator Copilot** | The GenAI assistant that helps capture, search, and reuse plant knowledge. |
| **Furnace-lining forecasting** | Predicting lining wear or degradation to avoid unplanned shutdowns and catastrophic failures. |
| **Energy dispatch optimization** | Scheduling energy-intensive production around electricity prices and carbon intensity. |
